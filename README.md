# vhs

Write terminal recordings from OCaml, and record cram tests as GIFs.

[VHS](https://github.com/charmbracelet/vhs), by Charm, records a terminal
session as an animated GIF (or a video) from a script. The script, a `.tape`
file, lists what to type and how long to wait, one command per line. Tapes are
easy to write by hand, but nothing checks them. When the program changes, the
GIF can go on showing what it used to do.

This library builds tapes as OCaml values, so a demo can be generated by the
same code that tests the program, and a change to the demo shows up in a
diff. It also turns a cram test (a file of shell commands with the output each
one must print, which dune checks) into a recording of that test. Making the
GIF itself still needs the `vhs` program.

## Installation

<!-- $MDX skip -->
```sh
$ opam install vhs
```

Until vhs is in the opam repository, install it from GitHub:

<!-- $MDX skip -->
```sh
$ opam pin add https://github.com/samoht/ocaml-vhs.git
```

To make GIFs, you also need [VHS](https://github.com/charmbracelet/vhs#installation)
itself.

## Usage

A tape is a list of steps. Settings such as the window size come first, then
what to type:

```ocaml
let tape =
  [
    Vhs.output "demo.gif";
    Vhs.set (Shell "bash");
    Vhs.set (Font_size 18);
    Vhs.set (Width 1000);
    Vhs.set (Height 560);
    Vhs.type' "dune test";
    Vhs.key Enter;
    Vhs.sleep (S 2.);
  ]
```

`Vhs.pp` prints the tape in the format VHS reads:

```ocaml
# Fmt.pr "%a" Vhs.pp tape;;
Output "demo.gif"
Set Shell "bash"
Set FontSize 18
Set Width 1000
Set Height 560
Type "dune test"
Enter
Sleep 2s
- : unit = ()
```

Each step raises `Invalid_argument` if VHS could not read it, for instance a
string holding a newline. `Vhs.render` runs `vhs` on the tape, and returns
an error when `vhs` is not installed or fails:

```ocaml
let make_gif env =
  let proc = Eio.Stdenv.process_mgr env in
  match Vhs.render ~proc tape with
  | Ok () -> ()
  | Error e -> Fmt.epr "%a@." Vhs.pp_error e
```

## Recording a cram test

A cram test is a `.t` file that dune runs: each line starting with `  $ ` is
a shell command, and the lines below it are the output it must print.
`Vhs.Cram` turns one into tape steps to put after the settings. Each command
is typed, and the recording waits for the shell prompt to come back before
moving on, so the GIF shows the output the command prints:

```ocaml
# let test = Result.get_ok (Vhs.Cram.parse "  $ echo hello\n  hello\n") in
  Fmt.pr "%a" Vhs.pp (Vhs.output "hello.gif" :: Vhs.Cram.items test);;
Output "hello.gif"
Type "echo hello"
Enter
Wait
Sleep 1s
- : unit = ()
```

The `vhs-cram` command does the same from the shell, and runs `vhs` on the
result. A setup script, if given, runs before the first command without
being recorded:

<!-- $MDX skip -->
```sh
$ vhs-cram --setup setup.sh --output demo.gif demo.t
```
